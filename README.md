# Balalite

터미널에서 즐기는 포커 로그라이크 팬게임 MVP입니다. 순수 Python 표준 라이브러리만 사용해서 별도 설치 없이 바로 실행할 수 있습니다 — 사무실 터미널 창 하나면 충분합니다.

> **비공식 팬게임 안내**
> 이 프로젝트는 [Balatro](https://www.playbalatro.com/)(제작: LocalThunk, 배급: Playstack)에서 영감을 받아 만든 **비공식·비영리 팬게임**입니다. 원작사와 아무런 관련이 없으며, 원작의 그래픽·사운드·텍스트 등 원본 에셋은 전혀 사용하지 않았습니다. 카드 등급표, 조커 밸런스, 보스 이름 등은 모두 이 프로젝트만의 자체 설계입니다. 상업적 목적이 없는 학습·오락용 프로젝트입니다.

## 실행 방법

Python 3.9 이상이 필요합니다 (표준 라이브러리 외 의존성 없음).

```bash
python3 -m balalite
# 또는
python3 run.py
```

## 게임 방법

- 52장의 표준 카드 덱에서 손패 8장을 받습니다.
- 카드 1~5장을 골라 포커 족보(하이 카드 ~ 스트레이트 플러시)를 만들어 **칩 × 배수** 점수를 냅니다. 족보별 기본 점수가 헷갈리면 언제든 `rank` 명령으로 족보표를, 카드 강화/에디션/씰 표시가 헷갈리면 `legend` 명령으로 범례를 볼 수 있습니다. 조커/소모품 목록에는 판매·사용 시 바로 쓸 수 있도록 번호가 함께 표시됩니다.
- 라운드마다 **플레이 4회, 버리기 3회**가 주어지며, 목표 점수(블라인드)에 도달하면 라운드 승리, 다 쓰기 전에 도달하지 못하면 게임 오버입니다.
- 블라인드를 이기면 상금을 받고 **상점**에서 조커(패시브 능력, 110종 — 그중 10종은 다른 조커와 상호작용하는 시너지 조커)와 소모품(부적/룬/강화석/에디션석/스펙트럴)을 구매할 수 있습니다. 조커는 최대 5개, 소모품은 최대 2개까지 보유 가능합니다.
- **조커 희귀도**: 커먼/언커먼/레어/레전더리 4단계가 있으며, 희귀할수록 상점에 덜 등장하고 효과가 강력합니다.
- 앤티는 1~8까지 있으며, 각 앤티마다 스몰 → 빅 → 보스 블라인드 순으로 진행합니다. 앤티 8의 보스 블라인드까지 클리어하면 승리합니다.
- **보스 블라인드**는 앤티마다 고유한 페널티(손패 축소, 버리기 금지, 특정 무늬/랭크 무효화, 특정 족보 무효화, 자금 징수, 한 번에 낼 수 있는 카드 수 제한, 조커 배수 효과 감소 등)를 겁니다. 화면에 효과가 항상 표시되며, 스테이크 5단계에서는 이 페널티들이 한층 더 가혹해집니다.
- **소모품**은 두 종류입니다: **부적(charm)**은 즉시 발동하는 1회성 효과(자금 획득, 다음 플레이 배수 2배, 무료 리드로우 등), **룬(rune)**은 특정 포커 족보의 기본 점수를 런 동안 영구히 강화합니다.
- **룬 12종**: 발라트로의 "행성 카드" 시스템에 해당하며, 표준 9족보(하이 카드~스트레이트 플러시)뿐 아니라 히든 족보 3종(파이브 오브 어 카인드/플러시 하우스/플러시 파이브)까지 전부 룬으로 강화할 수 있습니다. 히든 족보는 표준 52장 덱만으로는 원래 불가능하지만, **와일드 강화 카드**가 무늬뿐 아니라 나머지 카드와 같은 랭크로도 인정돼 마지막 한 장을 채워주면서 완성됩니다 (예: King 3장 + 와일드 2장 = 파이브 오브 어 카인드).
- 조커는 언제든 구매가의 절반 가격에 판매할 수 있고, 상점에서 마음에 드는 상품이 없으면 돈을 내고 리롤할 수 있습니다.
- 타이틀에서 새 게임을 시작하면 시드 → **덱 선택** → **스테이크(난이도) 선택** 순서로 물어봅니다. 시드는 같은 카드 순서로 재현 가능한 런을 시작할 때 사용하며 비워두면 매번 무작위입니다.
- **이자**: 블라인드를 클리어하면 보유 금액 $5당 $1의 이자를 추가로 받습니다 (기본 상한 $5, 저축 바우처로 상한 증가).
- **상점 구조** (발라트로와 동일하게 영역이 분리됨): **카드 슬롯**(조커 또는 소모품이 무작위로 나오는 슬롯, 기본 2개, "안목의 증표" 바우처로 증가 — 강화석·룬 보장 로직 때문에 실제로는 2~4개로 늘어날 수 있음) + **부스터 팩 슬롯**(고정 2개, 카드 슬롯과 경쟁하지 않고 항상 진열) + **바우처 슬롯**(미보유 바우처가 있으면 항상 1개). 손패 크기, 플레이/버리기 횟수, 상점 할인율, 이자 상한, 카드 슬롯 수, **조커·소모품 슬롯 자체**를 영구히 강화하는 바우처는 1회성 구매 아이템입니다.
- **상점 리롤 비용 상승**: 같은 상점 방문 안에서 `r`로 리롤할 때마다 비용이 $1씩 오릅니다 (기본 $2 → $3 → $4 ...). 다음 상점 방문에서는 다시 기본 비용으로 초기화됩니다.
- **덱 선택 (8종)**: 손패 크기/시작 자금/조커·소모품 슬롯/블라인드 난이도/상점 리롤가 등을 트레이드오프로 바꾸는 런 시작 규칙입니다. 자세한 목록은 아래 "게임 가이드"를 참고하세요.
- **스테이크 (난이도, 5단계)**: 숫자가 높을수록 어려워지며 효과가 누적됩니다 (2단계 이상이면 1단계 효과도 함께 적용). 자세한 목록은 아래 "게임 가이드"를 참고하세요.
- **블라인드 스킵**: 스몰/빅 블라인드에서 아직 플레이나 버리기를 하지 않았다면 `skip` 명령으로 블라인드를 건너뛰고 대신 태그(즉시 자금, 무료 조커, 무료 바우처 중 하나)를 받을 수 있습니다. 보스 블라인드는 스킵할 수 없습니다.
- **카드 강화**: 상점에서 파는 강화석을 손패의 특정 카드 한 장에 사용하면 그 카드는 런 내내(다음 라운드에도) 강화 상태를 유지합니다 — 보너스(+30칩), 멀티(+4 Mult), 와일드(플러시 판정 시 모든 무늬로 인정되고, 나머지 카드가 전부 같은 랭크일 때 히든 족보 완성도 도와줌), 유리(Mult x2, 이후 25% 확률로 파괴되어 덱에서 영구히 사라짐). 강화가 있으면 괄호 모양이 `⟦♠ K⟧`처럼 바뀌고 강화 종류에 따라 색이 달라지며(색 없이도 모양으로 구분 가능), 에디션이 있으면 카드 전체가 반전되어 빛나는 것처럼 보이고, 씰이 있으면 카드 앞에 색점(●)이 붙습니다. 표시 규칙이 헷갈리면 `legend` 명령으로 언제든 범례를 볼 수 있습니다. 강화석/에디션석/인장석(네거티브 포함) 중 하나와 룬 중 하나는 각각 매 상점 방문마다 최소 1개는 반드시 진열되도록 보장되어 있어, 강화 시스템과 룬 시스템을 놓치지 않고 발견할 수 있습니다.
- **에디션 4종** (발라트로와 동일한 규모): 포일(+50칩)/홀로그래픽(+10 Mult)/폴리크롬(Mult x1.5)은 플레잉 카드에 붙는 에디션이고(강화와 별개 슬롯이라 동시에 가질 수 있음), **네거티브**는 실제 발라트로처럼 카드가 아니라 **조커·소모품**에 붙어서 그 조커/소모품이 보유 슬롯을 차지하지 않게 만듭니다 (사실상 영구 슬롯 +1). 상점에서 파는 "네거티브 조커석/네거티브 소모품석"으로 보유 중인 조커·소모품 1개를 선택해 부여합니다. 네거티브가 붙은 조커/소모품 이름 옆에는 ✦ 표시가 붙습니다.
- **스펙트럴 카드**: 소모품의 세 번째 종류로, 더 파격적인 1회성 효과를 냅니다 — 안개(이번 플레이 조커 효과 2배), 메아리(라운드 내내 +2 Mult 누적), 저주(손패 무작위 카드에 무작위 강화 부여), 파괴(지정 카드 영구 제거), 행운($15), 복제(보유 조커 무작위 복제).
- **카드 씰**: 강화·에디션과 별개인 세 번째 슬롯입니다 — 적색(점수 포함 시 강화·에디션 효과 레트리거), 금색(플레이할 때마다 +$3), 청색(버릴 때 무료 소모품 1개 획득). 인장석 소모품으로 부여합니다.
- **부스터 팩**: 카드 슬롯과 별개로 전용 슬롯 2개에 항상 진열되며, 사면 즉시 여러 후보 중 일부를 무료로 골라 가질 수 있습니다 (예: 3개 중 1개, 점보는 4개 중 2개). 조커 팩/소모품 팩뿐 아니라 **카드 팩**도 있는데, 여기서 고른 플레잉 카드는 (이미 강화·에디션·씰이 붙어 있을 수 있는 채로) 덱에 새로 추가되어 52장보다 많아집니다.
- **저장/이어하기**: 라운드/상점 화면에서 `save` 명령으로 현재 진행 상황(덱, 손패, 조커, 소모품, 자금, RNG 상태까지)을 저장하고 종료할 수 있습니다. 다음 실행 시 타이틀 화면에서 `c`로 정확히 그 지점부터 이어할 수 있습니다. 저장 슬롯은 1개뿐이며, 런을 끝까지 마치면(승리 또는 게임 오버) 저장 파일은 자동 삭제됩니다.

### 명령어

라운드 화면:

| 명령어 | 설명 |
| --- | --- |
| `p 1 3 5` | 1, 3, 5번 카드를 플레이 |
| `d 2 4` | 2, 4번 카드를 버리고 새로 뽑기 |
| `u 1 [대상번호]` | 1번 소모품 사용 (강화석/에디션석/인장석/'파괴' 스펙트럴은 대상이 필요 — 카드는 손패 번호, 네거티브 조커·소모품석은 화면에 표시된 조커/소모품 목록 번호, 예: `u 1 3`) |
| `x 1` | 1번 조커 판매 (화면에 표시된 조커 목록 번호, 구매가 절반 환불) |
| `skip` | (아직 행동하지 않은 스몰/빅 블라인드에서) 블라인드 스킵, 태그 획득 |
| `s` | 손패 정렬 방식(랭크/무늬) 전환 |
| `rank` | 족보표(하이 카드~플러시 파이브까지 12종 기본 점수, 룬 레벨 적용 결과) 보기 |
| `j` | 보유 조커/소모품/바우처/족보 강화 정보 보기 |
| `legend` | 카드 강화/에디션/씰 표시 범례(색/기호 의미) 보기 |
| `save` | 저장 후 종료 (다음 실행 시 이어하기) |
| `h` | 도움말 |
| `q` | 게임 종료 (저장 안 함) |

상점 화면:

| 명령어 | 설명 |
| --- | --- |
| `b 1` | 1번 상품(조커/소모품/바우처/부스터 팩) 구매 |
| `r` | 상점 새로고침 (유료) |
| `x 1` | 1번 조커 판매 (화면에 표시된 조커 목록 번호) |
| `c` | 다음 블라인드로 진행 |
| `save` | 저장 후 종료 |

부스터 팩 개봉 화면:

| 명령어 | 설명 |
| --- | --- |
| `pick 1` | 1번 후보를 무료로 획득 |
| `skip` | 남은 선택을 포기하고 상점으로 복귀 |

## 게임 가이드

플레이 중 `rank`(족보표) / `j`(보유 정보) / `legend`(강화·에디션·씰 범례) 명령으로도 확인할 수 있는 내용을 여기 한 번에 정리했습니다.

### 족보표 (룬으로 강화되는 12종)

표준 9족보 + 와일드 강화 카드로만 완성 가능한 히든 3족보(파이브 오브 어 카인드/플러시 하우스/플러시 파이브)까지 총 12종입니다. "룬 레벨당"은 해당 족보의 룬을 살 때마다 영구히 누적되는 보너스입니다.

| 족보 | 기본 점수 | 룬 레벨당 보너스 |
| --- | --- | --- |
| 하이 카드 | 5칩 × 1배 | +5칩 · +1배 |
| 페어 | 10칩 × 2배 | +10칩 · +1배 |
| 투 페어 | 20칩 × 2배 | +15칩 · +1배 |
| 트리플 | 30칩 × 3배 | +20칩 · +2배 |
| 스트레이트 | 30칩 × 4배 | +25칩 · +2배 |
| 플러시 | 35칩 × 4배 | +20칩 · +2배 |
| 풀 하우스 | 40칩 × 4배 | +25칩 · +2배 |
| 포카드 | 60칩 × 7배 | +30칩 · +3배 |
| 스트레이트 플러시 | 100칩 × 8배 | +40칩 · +4배 |
| 파이브 오브 어 카인드 *(히든)* | 120칩 × 10배 | +35칩 · +4배 |
| 플러시 하우스 *(히든)* | 140칩 × 12배 | +40칩 · +5배 |
| 플러시 파이브 *(히든)* | 160칩 × 15배 | +50칩 · +6배 |

### 룬 (12종)

```
  cards.py        카드/덱 정의 (시드 가능한 RNG, 카드 강화 상태를 런 전체에서 유지)
  scoring.py      포커 족보 판정 및 기본 점수표
  jokers.py       조커 110종 정의(희귀도, 시너지/누적 훅 포함)와 점수 적용 로직
  consumables.py  부적/룬/강화석/에디션석(네거티브 포함)/인장석/스펙트럴 소모품 정의
  vouchers.py     상점에서 구매하는 영구 강화 바우처
  tags.py         블라인드 스킵 시 받는 태그 보상
  packs.py        부스터 팩(조커/소모품/카드 중 선택) 정의
  blinds.py       앤티/블라인드 목표 점수 및 보스 효과 계산(18종, 스테이크 5단계에서 강화)
  decks.py        런 시작 규칙이 달라지는 덱 종류(8종) 정의
  stakes.py       난이도 단계(스테이크, 5단계 누적) 정의
  game.py         게임 상태와 라운드/상점/팩 진행 로직, 저장·불러오기 직렬화
  save.py         저장 파일 경로 관리와 JSON 입출력
  ui.py           터미널 렌더링 (ANSI 컬러)
  cli.py          입력 파싱과 메인 루프
tests/            unittest 기반 단위 테스트
```

## 테스트

```bash
python3 -m unittest discover -s tests
```

## 향후 확장 아이디어 (백로그)

- `curses` 기반 풀스크린 UI — 현재는 print 기반 ANSI 렌더링을 의도적으로 유지했습니다. curses는 실제 tty가 필요해 파이프 입력 기반 자동 테스트/CI가 어려워지고 크로스플랫폼 리스크가 커지는 반면, 게임플레이 깊이에 대한 기여는 적어 우선순위를 낮췄습니다.
- 추가 카드 강화 종류(스틸/스톤/골드/럭키)
- 조커 순서를 직접 재배치하는 명령 (지금은 구매/획득한 순서로 고정되며, "메아리 지휘자" 등 인접 조커를 참조하는 시너지 조커의 발동 순서도 이 고정 순서를 따릅니다)
- 바우처 단계 업그레이드(1단계 구매 시 2단계가 나중에 풀리는 구조)
- 다중 저장 슬롯(현재는 1개 고정), 메타 진행(언락/도감/업적)
- 앤티 8 승리 이후 이어지는 엔드리스 모드
