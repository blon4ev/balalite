# LAST WAVE (라스트 웨이브)

터미널에서 즐기는 카드 콤보 서바이벌 로그라이크입니다. 해가 지면 몰려오는 몬스터 웨이브를 카드 콤보로 물리치며 스테이지 8까지 생존하는 게 목표입니다. 순수 Python 표준 라이브러리만 사용해서 별도 설치 없이 바로 실행할 수 있습니다 — 사무실 터미널 창 하나면 충분합니다.

> **개발 노트 (게임 시스템 계보)**
> 이 프로젝트의 점수 계산·상점 경제·로그라이크 진행 구조는 [Balatro](https://www.playbalatro.com/)(제작: LocalThunk, 배급: Playstack)에서 영감을 받아 설계했습니다. 다만 카드 콤보 이름을 제외한 모든 명칭(유물, 웨이브, 스테이지, 생존자, 위협도 등)과 세계관, 밸런스 수치, 보스 이름 등은 이 프로젝트만의 자체 설계이며, 원작의 그래픽·사운드·텍스트·조커 이름 등 원본 에셋은 전혀 사용하지 않았습니다. 원작사와 아무런 관련이 없는 비공식·비상업적 프로젝트입니다.

## 실행 방법

Python 3.9 이상이 필요합니다 (표준 라이브러리 외 의존성 없음).

```bash
python3 -m balalite
# 또는
python3 run.py
```

## 게임 방법

- 52장의 카드 덱에서 카드 패 8장을 받습니다.
- 카드 1~5장을 골라 콤보(하이 카드 ~ 스트레이트 플러시)를 만들어 몬스터에게 **데미지 × 배율**만큼 피해를 입힙니다. 콤보별 기본 데미지가 헷갈리면 언제든 `rank` 명령으로 콤보표를, 카드 강화/코팅/각인 표시가 헷갈리면 `legend` 명령으로 범례를 볼 수 있습니다. 유물/보급품 목록에는 판매·사용 시 바로 쓸 수 있도록 번호가 함께 표시됩니다.
- 웨이브마다 **공격 4회, 재정비(버리기) 3회**가 주어지며, 목표 데미지에 도달하면 몬스터 처치, 다 쓰기 전에 도달하지 못하면 전멸(게임 오버)입니다.
- 몬스터를 처치하면 전리품(자금)을 받고 **보급소**에서 유물(패시브 효과, 110종 — 그중 10종은 다른 유물과 상호작용하는 시너지 유물)과 보급품(부적/교범/강화 키트/코팅제 등)을 구매할 수 있습니다. 유물은 최대 5개, 보급품은 최대 2개까지 보유 가능합니다.
- **유물 희귀도**: 커먼/언커먼/레어/레전더리 4단계가 있으며, 희귀할수록 보급소에 덜 등장하고 효과가 강력합니다.
- 스테이지는 1~8까지 있으며, 각 스테이지마다 1차 웨이브 → 2차 웨이브 → 보스 웨이브 순으로 진행합니다. 스테이지 8의 보스 웨이브까지 처치하면 생존 성공입니다.
- **보스 웨이브**는 스테이지마다 고유한 몬스터 특성(카드 패 축소, 재정비 금지, 특정 무늬/랭크 무효화, 특정 콤보 무효화, 자금 약탈, 한 번에 낼 수 있는 카드 수 제한, 유물 배율 효과 감소 등)을 겁니다. 화면에 특성이 항상 표시되며, 위협도 5단계에서는 이 특성들이 한층 더 흉포해집니다.
- **보스 처치 전리품 보장**: 보스 웨이브를 처치하면 다음 보급소에 유물이 최소 1개는 반드시 진열됩니다 — 보스를 잡으면 확실한 득템이 있는 구조입니다.
- **보급품**은 여러 종류입니다: **부적**은 즉시 발동하는 1회성 효과(자금 획득, 다음 공격 배율 2배, 무료 재정비 등), **교범**은 특정 콤보의 기본 데미지를 생존 기간 내내 영구히 강화합니다.
- **교범 12종**: 표준 9콤보(하이 카드~스트레이트 플러시)뿐 아니라 히든 콤보 3종(파이브 오브 어 카인드/플러시 하우스/플러시 파이브)까지 전부 교범으로 강화할 수 있습니다. 히든 콤보는 표준 52장 덱만으로는 원래 불가능하지만, **와일드 강화 카드**가 무늬뿐 아니라 나머지 카드와 같은 랭크로도 인정돼 마지막 한 장을 채워주면서 완성됩니다 (예: King 3장 + 와일드 2장 = 파이브 오브 어 카인드).
- 유물은 언제든 구매가의 절반 가격에 판매할 수 있고, 보급소에 마음에 드는 물자가 없으면 돈을 내고 재고를 새로고침할 수 있습니다.
- 타이틀에서 새 게임을 시작하면 시드 → **생존자 선택** → **위협도(난이도) 선택** 순서로 물어봅니다. 시드는 같은 카드 순서로 재현 가능한 판을 시작할 때 사용하며 비워두면 매번 무작위입니다.
- **이자**: 몬스터를 처치하면 보유 자금 $5당 $1의 이자를 추가로 받습니다 (기본 상한 $5, 저축 훈련으로 상한 증가).
- **보급소 구조**: **카드 슬롯**(유물 또는 보급품이 무작위로 나오는 슬롯, 기본 2개, "안목 훈련"으로 증가 — 강화 키트·교범 보장 로직 때문에 실제로는 2~4개로 늘어날 수 있음) + **보급 상자 슬롯**(고정 2개, 카드 슬롯과 경쟁하지 않고 항상 진열) + **훈련 프로그램 슬롯**(미보유 프로그램이 있으면 항상 1개). 카드 패 크기, 공격/재정비 횟수, 보급소 할인율, 이자 상한, 카드 슬롯 수, **유물·보급품 슬롯 자체**를 영구히 강화하는 훈련 프로그램은 1회성 구매 아이템입니다.
- **보급소 리롤 비용 상승**: 같은 방문 안에서 `r`로 재고를 새로고침할 때마다 비용이 $1씩 오릅니다 (기본 $2 → $3 → $4 ...). 다음 방문에서는 다시 기본 비용으로 초기화됩니다.
- **생존자 선택 (8종)**: 카드 패 크기/시작 자금/유물·보급품 슬롯/웨이브 난이도/보급소 리롤가 등을 트레이드오프로 바꾸는 시작 규칙입니다. 자세한 목록은 아래 "게임 가이드"를 참고하세요.
- **위협도 (난이도, 5단계)**: 숫자가 높을수록 어려워지며 효과가 누적됩니다 (2단계 이상이면 1단계 효과도 함께 적용). 자세한 목록은 아래 "게임 가이드"를 참고하세요.
- **웨이브 회피**: 1차/2차 웨이브에서 아직 공격이나 재정비를 하지 않았다면 `skip` 명령으로 웨이브를 건너뛰고 대신 포상(즉시 자금, 무료 유물, 무료 훈련 프로그램 중 하나)을 받을 수 있습니다. 보스 웨이브는 회피할 수 없습니다.
- **카드 강화**: 보급소에서 파는 강화 키트를 카드 패의 특정 카드 한 장에 사용하면 그 카드는 생존 기간 내내(다음 웨이브에도) 강화 상태를 유지합니다 — 보너스(+30데미지), 멀티(+4 배율), 와일드(플러시 판정 시 모든 무늬로 인정되고, 나머지 카드가 전부 같은 랭크일 때 히든 콤보 완성도 도와줌), 유리(배율 x2, 이후 25% 확률로 파괴되어 덱에서 영구히 사라짐). 강화가 있으면 괄호 모양이 `⟦♠ K⟧`처럼 바뀌고 강화 종류에 따라 색이 달라지며(색 없이도 모양으로 구분 가능), 코팅이 있으면 카드 전체가 반전되어 빛나는 것처럼 보이고, 각인이 있으면 카드 앞에 색점(●)이 붙습니다. 표시 규칙이 헷갈리면 `legend` 명령으로 언제든 범례를 볼 수 있습니다. 강화 키트/코팅제/각인석(네거티브 포함) 중 하나와 교범 중 하나는 각각 매 보급소 방문마다 최소 1개는 반드시 진열되도록 보장되어 있어, 강화 시스템과 교범 시스템을 놓치지 않고 발견할 수 있습니다.
- **코팅 4종**: 포일(+50데미지)/홀로그래픽(+10 배율)/폴리크롬(배율 x1.5)은 플레잉 카드에 붙는 코팅이고(강화와 별개 슬롯이라 동시에 가질 수 있음), **네거티브**는 카드가 아니라 **유물·보급품**에 붙어서 그 유물/보급품이 보유 슬롯을 차지하지 않게 만듭니다 (사실상 영구 슬롯 +1). 보급소에서 파는 "네거티브 유물석/네거티브 보급품석"으로 보유 중인 유물·보급품 1개를 선택해 부여합니다. 네거티브가 붙은 유물/보급품 이름 옆에는 ✦ 표시가 붙습니다.
- **이능 물질**: 보급품의 세 번째 종류로, 더 파격적인 1회성 효과를 냅니다 — 안개(이번 공격 유물 효과 2배), 메아리(웨이브 내내 +2 배율 누적), 저주(카드 패 무작위 카드에 무작위 강화 부여), 파괴(지정 카드 영구 제거), 행운($15), 복제(보유 유물 무작위 복제).
- **카드 각인**: 강화·코팅과 별개인 세 번째 슬롯입니다 — 적색(판정 포함 시 강화·코팅 효과 재발동), 금색(공격할 때마다 +$3), 청색(버릴 때 무료 보급품 1개 획득). 각인석으로 부여합니다.
- **보급 상자**: 카드 슬롯과 별개로 전용 슬롯 2개에 항상 진열되며, 사면 즉시 여러 후보 중 일부를 무료로 골라 가질 수 있습니다 (예: 3개 중 1개, 대형은 4개 중 2개). 유물 상자/물자 상자뿐 아니라 **무기고 상자**도 있는데, 여기서 고른 카드는 (이미 강화·코팅·각인이 붙어 있을 수 있는 채로) 덱에 새로 추가되어 52장보다 많아집니다.
- **저장/이어하기**: 웨이브/보급소 화면에서 `save` 명령으로 현재 진행 상황(생존자, 카드 패, 유물, 보급품, 자금, RNG 상태까지)을 저장하고 종료할 수 있습니다. 다음 실행 시 타이틀 화면에서 `c`로 정확히 그 지점부터 이어할 수 있습니다. 저장 슬롯은 1개뿐이며, 판을 끝까지 마치면(생존 성공 또는 전멸) 저장 파일은 자동 삭제됩니다.

### 명령어

웨이브 화면:

| 명령어 | 설명 |
| --- | --- |
| `p 1 3 5` | 1, 3, 5번 카드로 공격 |
| `d 2 4` | 2, 4번 카드를 버리고 재정비(새로 뽑기) |
| `u 1 [대상번호]` | 1번 보급품 사용 (강화 키트/코팅제/각인석/'파괴' 이능 물질은 대상이 필요 — 카드는 카드 패 번호, 네거티브 유물·보급품석은 화면에 표시된 유물/보급품 목록 번호, 예: `u 1 3`) |
| `x 1` | 1번 유물 판매 (화면에 표시된 유물 목록 번호, 구매가 절반 환불) |
| `skip` | (아직 행동하지 않은 1·2차 웨이브에서) 웨이브 회피, 포상 획득 |
| `s` | 카드 패 정렬 방식(랭크/무늬) 전환 |
| `rank` | 콤보표(하이 카드~플러시 파이브까지 12종 기본 데미지, 교범 레벨 적용 결과) 보기 |
| `j` | 보유 유물/보급품/훈련 프로그램/콤보 숙련도 정보 보기 |
| `legend` | 카드 강화/코팅/각인 표시 범례(색/기호 의미) 보기 |
| `save` | 저장 후 종료 (다음 실행 시 이어하기) |
| `h` | 도움말 |
| `q` | 게임 종료 (저장 안 함) |

보급소 화면:

| 명령어 | 설명 |
| --- | --- |
| `b 1` | 1번 물자(유물/보급품/훈련 프로그램/보급 상자) 구매 |
| `r` | 보급소 재고 새로고침 (유료) |
| `x 1` | 1번 유물 판매 (화면에 표시된 유물 목록 번호) |
| `c` | 다음 웨이브로 진행 |
| `save` | 저장 후 종료 |

보급 상자 개봉 화면:

| 명령어 | 설명 |
| --- | --- |
| `pick 1` | 1번 후보를 무료로 획득 |
| `skip` | 남은 선택을 포기하고 보급소로 복귀 |

## 게임 가이드

플레이 중 `rank`(콤보표) / `j`(보유 정보) / `legend`(강화·코팅·각인 범례) 명령으로도 확인할 수 있는 내용을 여기 한 번에 정리했습니다.

### 콤보표 (교범으로 강화되는 12종)

표준 9콤보 + 와일드 강화 카드로만 완성 가능한 히든 3콤보(파이브 오브 어 카인드/플러시 하우스/플러시 파이브)까지 총 12종입니다. "교범 레벨당"은 해당 콤보의 교범을 살 때마다 영구히 누적되는 보너스입니다.

| 콤보 | 기본 데미지 | 교범 레벨당 보너스 |
| --- | --- | --- |
| 하이 카드 | 5데미지 × 1배 | +5데미지 · +1배 |
| 페어 | 10데미지 × 2배 | +10데미지 · +1배 |
| 투 페어 | 20데미지 × 2배 | +15데미지 · +1배 |
| 트리플 | 30데미지 × 3배 | +20데미지 · +2배 |
| 스트레이트 | 30데미지 × 4배 | +25데미지 · +2배 |
| 플러시 | 35데미지 × 4배 | +20데미지 · +2배 |
| 풀 하우스 | 40데미지 × 4배 | +25데미지 · +2배 |
| 포카드 | 60데미지 × 7배 | +30데미지 · +3배 |

### 위협도 (난이도, 5단계 누적)

숫자가 높을수록 아래 효과가 전부 누적 적용됩니다 (5단계 = 2~5단계 효과 전부 적용).

| 단계 | 이름 | 추가 효과 |
| --- | --- | --- |
| 1 | 평온 | 없음 |
| 2 | 긴축 | 1차 웨이브 처치 보상 없음 |
| 3 | 압박 | 웨이브 목표 데미지 +10% |
| 4 | 인색 | 웨이브당 재정비 -1회 |
| 5 | 최후의 밤 | 유물 슬롯 -1개, 보스 웨이브 특성 강화 |

## 프로젝트 구조

```
balalite/
  cards.py        카드/덱 정의 (시드 가능한 RNG, 카드 강화 상태를 생존 기간 내내 유지)
  scoring.py      카드 콤보 판정 및 기본 데미지표
  jokers.py       유물 110종 정의(희귀도, 시너지/누적 훅 포함)와 데미지 적용 로직
  consumables.py  부적/교범/강화 키트/코팅제(네거티브 포함)/각인석/이능 물질 보급품 정의
  vouchers.py     보급소에서 구매하는 영구 강화 훈련 프로그램
  tags.py         웨이브 회피 시 받는 포상
  packs.py        보급 상자(유물/보급품/카드 중 선택) 정의
  blinds.py       스테이지/웨이브 목표 데미지 및 보스 특성 계산(18종, 위협도 5단계에서 강화)
  decks.py        시작 규칙이 달라지는 생존자 종류(8종) 정의
  stakes.py       난이도 단계(위협도, 5단계 누적) 정의
  game.py         게임 상태와 웨이브/보급소/상자 진행 로직, 저장·불러오기 직렬화
  save.py         저장 파일 경로 관리와 JSON 입출력
  ui.py           터미널 렌더링 (ANSI 컬러)
  cli.py          입력 파싱과 메인 루프
tests/            unittest 기반 단위 테스트
```

내부 모듈/함수 이름(`blinds.py`, `Blind`, `boss_effect`, `JOKER_POOL` 등)은 예전 설계 당시의 이름을 그대로 유지하고 있습니다 — 엔진 로직은 전혀 바뀌지 않았고 화면에 보이는 텍스트만 리스킨했기 때문입니다.

## 향후 확장 아이디어 (백로그)

- `curses` 기반 풀스크린 UI — 현재는 print 기반 ANSI 렌더링을 의도적으로 유지했습니다. curses는 실제 tty가 필요해 파이프 입력 기반 자동 테스트/CI가 어려워지고 크로스플랫폼 리스크가 커지는 반면, 게임플레이 깊이에 대한 기여는 적어 우선순위를 낮췄습니다.
- 추가 카드 강화 종류(스틸/스톤/골드/럭키)
- 유물 순서를 직접 재배치하는 명령 (지금은 구매/획득한 순서로 고정되며, "메아리 지휘자" 등 인접 유물을 참조하는 시너지 유물의 발동 순서도 이 고정 순서를 따릅니다)
- 훈련 프로그램 단계 업그레이드(1단계 구매 시 2단계가 나중에 풀리는 구조)
- 다중 저장 슬롯(현재는 1개 고정), 메타 진행(언락/도감/업적)
- 스테이지 8 생존 성공 이후 이어지는 엔드리스 모드
